# To-Do List GUI Application Using Python

A graphical To-Do List application developed using Python and Tkinter. This project provides a separate desktop window where users can easily add, view, complete, and delete their daily tasks.

## Features
- Add new tasks.
- Display tasks in a list.
- Mark tasks as completed.
- Delete selected tasks.
- Display task status as Pending or Completed.
- Interactive desktop application window.

## Technologies Used
- Python
- Tkinter
- PyCharm

## Purpose
This project was developed to understand Python GUI programming and learn how to build interactive desktop applications using Tkinter.
